# 电商用户行为数据分析项目

> 用两份公开数据集搭建「流量 → 转化 → 留存 → 复购」全链路指标体系，定位转化瓶颈并对客户做 RFM 价值分层，最终输出可落地的运营建议。

## 数据来源（均为公开数据集）

| 数据集 | 来源 | 用量 | 用途 |
| --- | --- | --- | --- |
| Online Retail | UCI Machine Learning Repository | 全量 54.2 万行，清洗后 39.8 万行 | GMV 拆解、商品结构、RFM 分层 |
| UserBehavior | 阿里巴巴天池 | 1 亿条中抽样 200 万行，清洗后 197.5 万行 | 转化漏斗、时段分析、留存与复购 |

## 技术栈

Python（pandas 清洗）→ MySQL 8（存储与指标计算，**核心指标全部用 SQL 实现**）→ Excel（可视化；看板可平滑迁移至 FineBI / PowerBI）

## 复现步骤

```bash
pip install pandas sqlalchemy pymysql openpyxl
py 01_清洗/clean_retail.py
py 01_清洗/clean_user_behavior.py
py 02_入库/run_sql.py create      # 建库建表
py 02_入库/load_to_mysql.py       # 导入数据
py 02_入库/run_sql.py retail      # GMV、商品、RFM 指标
py 02_入库/run_sql.py behavior    # 漏斗、时段、留存指标
py 03_指标/export_results.py      # 导出结果到 05_报告/指标结果.xlsx
```

## 指标体系

**流量层**：PV / UV / 人均浏览量 / 时段活跃与转化分布
**转化层**：浏览 → 兴趣 → 加购 → 下单 四级漏斗（严格按用户交集口径计算）
**商品层**：热销 Top10、二八分布、地区结构
**用户层**：RFM 八分层、次日与 7 日留存、复购率

## 核心结论

- **加购未下单 4,131 人，流失率 28.22%**，是全链路最大流失点；另有 2,775 人未加购直接下单
- **22.91% 的重要价值客户贡献 65.43% 的 GMV**；重要挽留客户 287 人平均 125.7 天未复购，是召回 ROI 最高人群
- **流量高峰 ≠ 转化高峰**：12–14 点行为量全天最高但下单转化仅 1.72%，凌晨 2–8 点流量小但转化达 2.33%–2.57%
- **二八分布成立**：3,665 个商品中仅 776 个（21.17%）贡献 80% 销售额
- 次日留存 74.63%，复购率 65.86%，GMV = 4,338 客户 × 4.27 单/人 × 480.87 客单价
